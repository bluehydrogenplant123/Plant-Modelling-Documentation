# Algorithm Configuration

Use **Algorithm** when you need to review or edit the solution algorithm library before starting computation.

## Where To Find It

1. Select the **Set Run** primary menu.
2. Click **Algorithm** in the secondary button row.
3. Select **SoluAlgoLib** from the dropdown.

## What It Opens/Does

The **Algorithm** dropdown contains **SoluAlgoLib**, which replaces the previous run-configuration algorithm flow.

Selecting **SoluAlgoLib** opens the solution algorithm library editor. The editor shows the solution algorithm phases and their collection or Objective Function assignments.

## Basic Steps

1. Open the **Algorithm** dropdown.
2. Choose **SoluAlgoLib**.
3. Review the phase rows, collection assignments, and Objective Function assignments.
4. Click **Save** if you made changes, or close the modal if you only reviewed the settings.

## Result

The saved SoluAlgoLib rows are ready for use when you open the **Run** computation panel.
