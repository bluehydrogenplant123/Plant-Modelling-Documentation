# Cost & revenue

Use **Cost & revenue** to maintain cost and revenue data for the current diagram.

## Before You Start

- Save a new diagram with the main **Save** action. Economic entries remain
  disabled until the diagram has been saved.
- A fresh diagram has no Cost or Revenue rows. Add rows or import them when
  needed.

## Steps

1. Open **User Tables**.
2. Click **Cost and Revenue Data**. The **Economic - Cost & revenue** modal
   opens.
3. Click **Add Cost & revenue**, or click **Import** to load rows from a CSV or
   Excel workbook.
4. Enter the **Cost & revenue Name**, **Value**, **Uncertainty**, **Unit**, and
   **Type**. **Uncertainty** must be between 0 and 1.
5. If the row must point to a model variable, click **Add Mapping** and select
   its **Network**, Cost or Revenue name, **Node**, **Port**, and **Var**.
6. Use **Delete** to remove an unwanted row or mapping. Use **Export** if you
   want a workbook copy of the current rows.
7. Click **Save** in the modal header.

## Result

The app shows **Cost & revenue saved successfully.** Reopening the panel
loads the saved rows and mappings. If you save after deleting the final row,
the panel remains empty when it is reopened.

## Troubleshooting

| Problem | What To Check |
| --- | --- |
| The Economic entries are disabled | Save the diagram with the main **Save** action first. |
| Save is rejected | Review the visible error message and confirm that every **Uncertainty** value is between 0 and 1. |
| Import fails | Use a `.csv`, `.xlsx`, or `.xls` file and correct the row reported in the error message. |
