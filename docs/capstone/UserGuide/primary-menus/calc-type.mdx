# Calc Type Menu

The **Calc Type** primary menu sets the calculation mode for the current network. The selected mode affects which node variable specifications are used in **TP Specs**.

## Secondary Buttons

Click a button name to open the detailed page for that calculation type.

| Button | What It Is For |
| --- | --- |
| **[Simulation](./calc-type/simulation)** | Use simulation mode. |
| **[Optimization](./calc-type/optimization)** | Select Objective Function / Constraint Sets and open Optimization specifications. |
| **[DataRec](./calc-type/data-rec)** | Select Instrument Sets, Plant Measurements, and Objective Function Sets for data reconciliation. |
| **[ParamUpdt](./calc-type/param-updt)** | Use parameter update mode. |

Clicking a different type opens **Switch Calc Type** first, then changes the mode and opens **TP Specs** after confirmation. When Simulation or ParamUpdt is already active, clicking its button opens **TP Specs** directly. When Optimization or DataRec is active, its button becomes a dropdown; use **Specification set** inside that dropdown to open **TP Specs**.

Calc Type buttons can be disabled while computation-related read-only rules are active.
