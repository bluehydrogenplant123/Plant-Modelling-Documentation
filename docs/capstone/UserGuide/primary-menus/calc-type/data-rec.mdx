# DataRec

Use **DataRec** when the current network should run in data reconciliation mode.

## Where To Find It

1. Select the **Calc Type** primary menu.
2. Click **DataRec** in the secondary button row.

## What It Opens/Does

When **DataRec** is selected, its secondary button becomes a dropdown with four setup panels:

- **Define Instruments** selects an Instrument Set and provides an entry to the Instrument Mapping editor.
- **Plant Measurements** selects any saved measurements from the active Instrument Set and provides an entry to the Measurements editor.
- **Objective function** selects saved Objective Function equations.
- **Specification set** opens the existing TP Specs panel.

If another calculation type is selected, clicking **DataRec** first opens **Switch Calc Type**.

Saving records in the Instrument Mapping, Measurements, `+Constr`, or TP Specs editors makes those records available for reuse. It does not select them for a run. Use **Apply** in each DataRec selector to commit the next-run choices; **Cancel** leaves the previous choices unchanged.

## Basic Steps

1. Open **Calc Type**.
2. Click **DataRec**.
3. If **Switch Calc Type** appears, click **Confirm** to switch to **DataRec**.
4. Open **Define Instruments**, choose an Instrument Set, and click **Apply**.
5. Open **Plant Measurements**, select the measurements to use, and click **Apply**.
6. Open **Objective function**, apply any required Objective Function equations, then use **Specification set** to review or edit TP Specs.

## Result

The network uses **DataRec** as its calculation mode. The active Instrument Set, selected Plant Measurements, and selected Objective Function equations control the next DataRec run. Changing the Instrument Set clears the measurement selection, and these run choices reset when the canvas Header is remounted or another network is opened.
