# Multi-TP Menu

Use **Multi-TP** for model-version, range, specification, and economic work that
varies by time period.

## Before You Start

- Save the diagram before opening data that is stored for that diagram.
- Verify the diagram before using **Global TP** or the Multi-TP economic items
  in **User Tables**.

## Secondary Controls

| Control | What It Is For |
| --- | --- |
| **Time Horizon** | A visible placeholder that is currently disabled. |
| **View Time Periods** | A visible placeholder that is currently disabled. |
| **[TP Node - Model Version Control](./multi-tp/tp-node-model-version-control)** | Open the TP node model-version workflow. |
| **[Global TP](./multi-tp/global-tp)** | Configure global time-period ranges and duration settings after verification. |
| **[TP Specs](./multi-tp/tp-specs)** | Review or edit TP-specific specification values. |
| **TP Data** | A visible placeholder with no current action. |
| **User Tables** | Open **Cost and Revenue Data** or **Supply and Demand Data** for Multi-TP rows. **Material Properties** is disabled in this menu. |

## Open Multi-TP Economic Data

1. Select the **Multi-TP** primary menu.
2. Open **User Tables** in the secondary controls.
3. Click **Cost and Revenue Data** or **Supply and Demand Data**.

The two economic items are enabled only when the current diagram is saved and
verified, and when economic editing is not restricted by the current
computation state.

## Result

The selected Multi-TP economic panel opens with the current diagram's TP rows.

## Troubleshooting

| Problem | What To Check |
| --- | --- |
| **Global TP** is not visible | Verify the diagram first. |
| The economic items in **User Tables** are disabled | Save and verify the diagram, then wait for any active computation restriction to finish. |
