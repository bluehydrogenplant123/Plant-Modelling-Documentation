# SoluAlgoLib

Use **SoluAlgoLib** when you need to configure solution algorithm library rows for the current diagram.

## Where To Find It

1. Select the **Set Run** primary menu.
2. Click **Algorithm** in the secondary button row.
3. Select **SoluAlgoLib** from the dropdown.

## What It Opens

The **SoluAlgoLib** dialog loads diagram-level collections and Objective Function equations. It lets you edit solution-algorithm library data, choose Constraint collections, choose single Objective Function equations for optimization phases, and save the row choices back to the current diagram.

## Basic Steps

1. Open **SoluAlgoLib**.
2. Review the loaded library rows.
3. Edit the required rows, collections, or Objective Function assignments.
4. Click **Save**.

## Result

The solution algorithm library configuration is saved with the current diagram.
