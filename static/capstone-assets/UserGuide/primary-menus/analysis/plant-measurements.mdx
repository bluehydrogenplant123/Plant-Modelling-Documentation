# Plant Measurements

Use **Plant Measurements** to connect model variables to instruments and save
measurement values in a measurement set.

## Before You Start

- Save the diagram first. Plant Measurements needs a saved diagram.
- Add the required nodes and variables to the diagram before creating their
  instrument mappings.

## Steps

1. Select the **Analysis** primary menu.
2. Click **Plant Measurements**.
3. Choose an existing **Measurement Set**. To create one, click **New
   Measurement Set**, choose a **Network**, review or edit the **Set Name**, and
   click **Create Set**.
4. Open the **Instrument Mapping** tab and click **Add Mapping**.
5. Complete the mapping fields: **Network**, **Subnetwork**, **Node**, **Port**,
   **Variable**, **Instrument**, **Units**, **LB**, **UB**, **Absolute Acc**,
   **% Accuracy**, and **Weight**.
6. Open the **Plant Measurements** tab. Click **Add Measurement** to enter a row,
   or click **Import** to load measurement rows from a CSV or Excel workbook.
7. Select rows and click **Remove Selected** when you need to remove them.
8. Click **Save**.
9. To remove the entire measurement set and all of its rows, click **Delete
   Set** and confirm the deletion.

## Result

The selected measurement set keeps its instrument mappings and plant
measurement rows. Selecting the set again reloads its saved data.

## Troubleshooting

| Problem | What To Check |
| --- | --- |
| The measurement sets do not load | Save the diagram first, then reopen **Plant Measurements**. |
| **Create Set** is disabled | Select a valid **Network** in the **New Measurement Set** dialog. |
| Save is rejected | Review the **Status** cells, then fix or remove invalid mapping or measurement rows. |
| An imported measurement is invalid | Confirm that **Instrument Name** matches one mapping in the selected set and that **Units** match the mapped instrument. |
