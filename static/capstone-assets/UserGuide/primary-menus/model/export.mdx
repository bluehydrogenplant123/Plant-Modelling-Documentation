# Export

Use **Export** when you need to download diagram data from the current network.

## Where To Find It

1. Select the **Model** primary menu.
2. Click **Export** in the secondary button row.

## What It Opens

The **Export Data** dialog lets you choose **Full Data**, **Solver Data**, or **Algorithm Data**. For **Full Data**, you can enter an **Export File Name**. The app adds `.json` automatically when needed.

When the source root diagram is verified, Full Data also offers two verification choices:

- **Preserve verified status** keeps the root status in the downloaded snapshot.
- **Export as Unverified** writes `isVerified: false` only in the downloaded root metadata, so an imported copy is editable.

An unverified source has no extra choice because both results would be unverified. Solver Data and Algorithm Data are unchanged.

## Basic Steps

1. Open **Export**.
2. Choose the export mode.
3. Enter an export file name if you selected **Full Data**.
4. For a verified source, choose whether to preserve the status or export an unverified copy.
5. Click **Export**.
6. Click **Cancel** if you do not want to export.

## Result

The selected export data is downloaded from the current diagram. Export never changes the source diagram in the database, and the unverified option does not rewrite nested subnetwork instance records.

The Dashboard Full Data export uses the same rule: for a verified source, confirm an editable unverified copy or cancel that confirmation to preserve the verified status.
