# Extract Selection

Use **Extract Selection** to create a separate network from part of the current
canvas.

## Before You Start

- Open a saved diagram that contains at least one node. You can select nodes on
  the canvas before opening the dialog or select them later in the **Preview**.
  Streams are optional.
- If the diagram has unsaved changes, opening **Extract Selection** saves the
  current diagram first. The dialog opens only after that save succeeds.

## Steps

1. Select the **Model** primary menu.
2. Click **Extract Selection**.
3. Review the **Selected nodes** and **Selected streams** counts and the
   **Preview**.
4. In the **Preview**, click nodes or streams, or drag a selection box, to
   adjust the extracted content.
5. Review or edit the **Network Name**. Enter a **Description** if needed.
6. Confirm that at least one node is selected, then click **Create**.

## Result

A separate diagram is created for the selected content. The new diagram opens
after creation succeeds.

## Troubleshooting

| Problem | What To Check |
| --- | --- |
| **Create** is disabled | Enter a **Network Name**, select at least one node, and wait for any save or creation in progress to finish. |
| The dialog does not open | Wait for the current diagram to save and resolve any save error shown by the app. |
| A selected count is incorrect | Adjust the selection in the **Preview** and check the counts again before clicking **Create**. |
