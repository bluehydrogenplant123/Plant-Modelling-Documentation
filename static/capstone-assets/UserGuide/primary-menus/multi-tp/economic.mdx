# Multi-TP Economic Data

Use the **User Tables** control under **Multi-TP** to maintain economic rows for
specific time-period ranges.

## Before You Start

- Save and verify the current diagram. Otherwise, the two economic items in the
  Multi-TP **User Tables** menu remain disabled.
- Use **Global TP** to configure the ranges you need. Without additional TP
  ranges, economic rows use the default range from TP 1 to TP 1.
- Create and save Base rows first if you plan to use **Apply Base Economic**.

## Steps

1. Select the **Multi-TP** primary menu.
2. Open **User Tables** in the secondary controls.
3. Click **Cost and Revenue Data** or **Supply and Demand Data**.
4. Select an existing Cost, Revenue, Demand, or Supply name. Use **Add Cost &
   revenue** or **Add Demand & Supply** to create another name.
5. Review each row's **From TP** and **To TP** values. **From TP** must be at
   least 1, and **To TP** must be greater than or equal to **From TP**.
6. Click **Add TP Row** if the selected name needs another range, then edit its
   range and values.
7. Under **Mappings**, select a name and use **Add Mapping Row** when the
   economic row must point to a model variable.
8. Click **Save** after manually changing rows or mappings.

## Apply Base Economic

**Apply Base Economic** replaces the existing Multi-TP rows and mappings for
the open panel with copies of its Base rows. The app creates one copy for each
current TP range and saves the copied data immediately.

Use this action only when you intend to replace the open panel's current
Multi-TP values. You do not need to click **Save** again unless you make more
manual changes afterward.

## From TP and To TP

- **From TP** and **To TP** define the range stored for one economic row.
- Opening the panel loads the diagram's current TP ranges. When the configured
  range set changes, the panel synchronizes its stored Multi-TP rows to the
  current ranges when required.
- Saving is rejected when **From TP** is less than 1 or **To TP** is less than
  **From TP**.

## Result

Manual saves show a **Multi-TP Cost & revenue saved successfully.** or
**Multi-TP Demand & Supply saved successfully.** message. Applying Base rows
shows a message that the Base data was applied to Multi-TP rows.

## Troubleshooting

| Problem | What To Check |
| --- | --- |
| The economic items are disabled | Save and verify the diagram, then wait for any computation restriction to finish. |
| **Apply Base Economic** reports that no Base rows are available | Open the top-toolbar **User Tables**, add and save Base rows for the same panel, then return to **Multi-TP**. |
| Save reports an invalid TP range | Set **From TP** to 1 or higher and make **To TP** greater than or equal to **From TP**. |
| The expected TP range is missing | Update the ranges in **Global TP**, then reopen the economic panel. |
